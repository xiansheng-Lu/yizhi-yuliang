# M2-13a 执行单与发送前尝试登记

负责人BE，无前端协作。WAITING_REVIEW，基线2915126。M2-11a/12真实技术输入；持续研发授权G0/E08保留。

三条DoD：非COMMAND不伪造command_job，每申请最多一个当前执行单；外部调用前持久SENT与平台稳定键，重复投递只查；attempt序号/平台键唯一、租户约束有效，旧尝试不覆盖。

## 实现与三条DoD

1. 0032增加execution_orders与execution_attempts，biz_type/biz_id与租户唯一。COMMAND_JOB精确关联原申请；其他业务类型的command_job_id必须为NULL，不能伪造命令申请。当前唯一真实生产者是COMMAND_JOB，其他业务源在对应M3卡实现前明确拒绝，没有用空执行单假装其他业务已接通。申请/执行/尝试/完整平台账户和目标均以复合外键约束，运行身份只读执行账。
2. prepare在短事务中完成实际EXECUTE风险检查、目标fence领取、原申请EXECUTING条件转移、首attempt=SENT、稳定platform_request_key/outbound_id和审计，提交后才可调用RecordedPlatformClient。SENT表示发送意图已持久化，不能单凭此字符串认定物理网络发生。每个attempt冻结独立授权版本、绑定、规范Schema/参数SHA256、审计安全投影与业务版本，后续重试不得覆盖旧尝试。序列化器必须由后端明确装配；默认缺省关闭，当前测试规范DTO不能当作ADQ真实协议。平台请求键由序列化端口交给已核验适配器使用，不猜测供应商是否支持幂等参数。
3. 首次准备只返回一次内存高熵发送凭证，数据库仅保存SHA256；repr/模型导出不含凭证。并发/重投/进程重新查询只返回同一order/attempt/key及在途元数据，不恢复发送资格或参数。实际根请求创建需要凭证、当前fence/租约、当前权限/授权/能力/策略/审批、刚完成的EXECUTE风险，以及实际参数/Schema与冻结摘要一致。根记录提交与物理HTTP之间另有原始ATTEMPT写入触发器再次检查资格；旧fence、过期租约不能靠已有根记录继续发写，禁止WRITE隐式第二次网络尝试。已有相同根请求重放只查留档，不再次HTTP。晚到RESPONSE/ERROR留档不因旧fence被删除，结果隔离归M2-13b。

dispatch风险入口只允许已经实际校验GuardLease的EXECUTING申请，普通EXECUTE接口仍要求APPROVED。核对冻结旧值和当前值、原意图HMAC、原始值来源合同的sourceId/field/policyRevision；不把每次刷新时钟当作意图变化。配额/资源准入后才做最终风险与一次性凭证消费；所有外部HTTP在归档根事务提交后执行。配额未准入或本地失败不会自动重发已准备SENT；恢复资格与未发送证明由M2-11b处理。

## 实际验证

20项真实PG专项：发送前从独立连接可读到SENT；稳定根重放仅一次Mock HTTP；四并发准备只有一执行单/尝试/首次凭证；缺少发送钩子、仅查询元数据、实际参数不同于闭包所验证参数均在根记录前拒绝且凭证消费回滚；fence、租约、授权版本、策略、能力、冻结旧值、来源合同改变均阻断；根记录已提交后fence失效，原始ATTEMPT触发器仍阻止物理HTTP；未接入其他业务与未注册序列化器不产生假申请或领取；运行身份及维护身份不可改旧attempt关键身份；序号/平台键唯一与跨租户外键生效；准备审计失败使领取/状态/SENT共同回滚，既有HELD保守保留。

真实PG/事务/并发/行锁与审计执行；审批前置阶段和供应商协议/响应明确为合成fixture，所有MockTransport调用不计真实平台验收。trace只留order/attempt/guard/稳定键与计数，没有secret、令牌或实际账户数据。完整命令、全量回归数量、开发库迁移见verification.json。
