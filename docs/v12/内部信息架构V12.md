# 内部信息架构 V12（R1）

新增 `/app/command` 为默认 AI运营指挥台。保留 21 个旧业务页面，总计 22 个业务入口。七组导航来自 `src/lib/routes.ts` 的 `navigationGroups`；原 `workspaces` 保留为 G1 路由兼容注册表，不再用于 V12 导航呈现。

| 新导航 | 路由与页面 |
| --- | --- |
| AI指挥台 | **新增** command：AI运营指挥台 |
| 任务中心 | tasks：AI任务与审批；executions：执行记录 |
| 直播运营 | monitor：AI直播作战室；products：商品与货盘 |
| 投放管理 | goals：经营目标；plans：投放计划；decisions：AI投手决策；budgets：跨平台预算 |
| 内容工厂 | planning：内容策划；scripts：脚本工厂；videos：视频工厂；graphics：图片图文；editing：智能剪辑；assets：素材资产库；experiments：素材测试 |
| 数据复盘 | overview：经营总览；analytics：经营分析；reports：完整复盘 |
| 管理设置 | agents：AI岗位管理；connections：平台连接；settings：企业与权限（旧页面标题“企业和权限设置”保留） |

所有 ID 使用 `/app/{id}`。当前分组默认展开，可手动折叠；手机侧栏通过菜单按钮打开，可用关闭按钮、遮罩或 Escape 关闭。关闭的手机导航不可聚焦。搜索检索上述全部工作区，当前页面具有 aria-current 标识。

默认登录和 `/app` 进入 `/app/command`。官网冻结文件原本使用 `next=overview` 表示默认工作台，该裸参数在登录目标解析中映射到 command，无需改变官网。显式 `/login?next=/app/overview`、旧 `#/overview` 仍访问经营总览；`campaigns → plans`、mobile 以及其他白名单深链保持兼容，非法目标只回退内部指挥台。

顶栏经营上下文复用原有 ScopeControls / Service：店铺、直播场次和平台，跨页保留，同一范围用于三项 KPI 和任务列表。账户级专业操作及平台子路由在 R3 实施；本轮未伪造账户授权或账户筛选能力。

会话历史搜索、会话重命名和跨模块任务属于 R2；当前搜索明确为“工作区搜索”。
