## 范围与行为

实现服务端固定的参数GET合同、独立只读端口、规范值比较器；直接复用原归档与READBACK配额。端口只接受READ、GET、幂等读取、单次网络尝试、实际账户及目标参数；默认未装配时关闭，不猜测ADQ/小店的路径、字段、精度或权限。

回读须为当前原申请/尝试，重新核对当前权限、账户、授权、原参数来源字段与策略版本；在归档准入前再查一次。普通同步暂停不关闭执行核验，授权撤销仍拒绝。短PG事务之外调用GET，比较从真正保存的白名单Raw读取，首次与重放走同一路径，不拿写响应回显充当核验。相同检查ID及合同摘要复用原出站档案；新检查的持久调度归M2-17b，不在本端口sleep或重试HTTP。

金额仅接受明确CNY的安全范围整数分，0是合法值；不推断元/分、币种或字符串数字。目标ROI要求显式平台精度及依据，按该精度比较，无法表示的申请返回不可核验；NaN、布尔、非有限值和溢出拒绝。暂停/恢复按同类型原生枚举映射，未知值不当False。合同禁止效果ROI/效果对象和敏感字段，缺少所需档案字段则准入前关闭。

两时钟分别记录抓取时间和可用的来源时间，不补造来源时间；过期重放、旧于受理回执的来源、未来时间、缺字段各有受控原因。比较结果只标E0，返回MATCHED/MISMATCH/UNREFRESHED/UNAVAILABLE，不修改任务、执行单、镜像、核验事实或预算。写回执未知时读到相同值也不产生平台受理证明。
