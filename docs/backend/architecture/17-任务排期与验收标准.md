# 17 任务排期与验收标准（任务粒度，面向 Coding Agent 下发）

本册把 11 册里程碑拆成可独立下发、独立验收的任务卡。不使用人天预算：每个任务有明确边界、规格引用、依赖与"可勾验"的完成定义（DoD），排期按任务吞吐与门禁推进，人力增减只影响并行度，不影响任务定义。

## 0. 总体评审结论（2026-10-26）

### 0.1 结论

12-16 册细化完成后，对全套 17 册做批判性复核，结论：**技术选型、资金安全模型、契约对齐、平台分期四件大事没有结构性问题，可以进入任务级排期与开发**。模块化单体 + 统一执行内核 + 六阶段能力治理的组合，与"一期腾讯系内部验证、二期复制平台"的目标匹配，未发现需要推翻重来的设计。

### 0.2 评审中发现并已在本轮修正的问题

| 问题 | 修正位置 |
|---|---|
| 13 册有执行域/内容域 DDL，但缺 shops/ad_accounts/products/live_sessions 等支撑表，导致 command_jobs 等表的 shop_id/account_id/product_id 是裸列，与 04 册"复合外键防跨租户拼装"矛盾 | 13 册新增 3.1 节目录域最小集 DDL 与复合外键写法 |

| 审批留痕表名混用 job_approvals 与 approvals | 04 册统一为 approvals（subject_type=COMMAND_JOB） |

### 0.3 开发期间必须盯住、不允许在任务中"顺手改掉"的架构约束

1. 状态只能经状态机 `transition()` 变更，禁止裸赋 status；对前端只暴露 12 态，UNKNOWN 投影规则不得简化（12 册）。
2. 写平台的事务不跨 HTTP；额度公式 `B+R+delta<=limit` 在行锁内校验；UNKNOWN 只查不重发（06/12/15 册）。
3. RLS 四段策略 + FORCE RLS + 应用账号无 BYPASSRLS，复合外键不允许省略（09/13 册）。
4. 一期不开发 ocean/xhs 适配器；其能力恒为 NOT_INTEGRATED，不做"先占位"（07/11 册）。
5. 字段命名跟随契约分组（command 蛇形、V8/V9/内容驼峰），不统一改名（05/14 册）。
6. 金额整数分、微信豆独立、ROI numeric；平台现值只信服务端回读，不信前端传值（01/04 册）。

### 0.4 仍需业务方拍板/供给的事项（不阻塞 M0，阻塞对应任务验收）

- D1 登录扫码是否一期做（默认不做，邮箱密码+验证码）；D6 服务器/域名/备案/证书（阻塞 M2 联调环境）。
- 腾讯广告 app_id/secret/灰度账户（阻塞 M1-06 起真实验收）；ADQ 小金额账户（阻塞 M2-G 真实写验收）。
- LLM 供应商密钥预算（M2-01 沙箱可用 mock key 开发，真实验收需要）；NEXORA 文档/密钥/回调（M3 内容生成验收）。
- 微信豆合法写接口的正式渠道结论（M4-08）。

## 1. 任务卡与下发规则

### 1.1 任务卡格式（每个任务按此下发给 Coding Agent）

```text
任务ID：M?-??
标题：
依赖任务：[ID 列表，无则写"无"]
规格输入：[分册章节、前端文件、契约文档路径]
改动范围：[允许新增/修改的目录与文件边界；边界外改动需退回]
交付物：[代码、迁移、种子数据、验收证据]
完成定义（DoD）：[可勾验清单，3-7 条]
人工门禁：[是否需要人工评审/真实账户操作/密钥]
禁止事项：[本任务不得做的事，防止越界]
```

### 1.2 规模点（不换算工时，仅用于排队和吞吐统计）

- S：单域单接口/单表/单策略，验收证据 <=3 组；
- M：跨两个模块或含一条完整状态转移/一条同步链路，验收证据 4-8 组；
- L：跨 API+Worker+平台边界，或含资金/状态机核心逻辑，必须双人评审 + 故障分支证据。

### 1.3 下发与合并纪律

1. 严格按依赖列下发；同里程碑内无依赖关系的任务可并行（建议每批 2-3 个，两个后端方向各领一条线）。
2. 每个任务一个分支（命名见 docs/git-workflow.md），完成后合主干；L 类任务必须人工评审，S/M 类可由 agent 自检 + 门禁任务复核。
3. 任务完成必须附"验收证据"：接口契约样例、状态转移表驱动用例、或故障演练记录（排期沿用 11 册已评审通过的集成验证要求；如不希望保留自动化测试，请在开发前指出，届时以人工演练记录替代）。
4. 任务中发现规格矛盾：停止扩散，先回改对应架构分册并在本任务卡记录，再继续；禁止任务内私自决策。
5. 所有代码注释简体中文、UTF-8、无 emoji；Windows + PowerShell 环境验证。
