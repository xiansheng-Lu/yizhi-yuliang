# ADGROUP 稳定跨页合同

本切片沿用既有 `POST /v1/delivery/integrations/queries` 与 V9 ResourcePage；会话、CSRF、scope、resource=adgroups 和父级原生 campaign ID 合同不变。真实前端 PlatformService 文件消费通过，BE/F11 具名复核及浏览器联调仍待验。

首屏不传 cursor，固定每页最多100行。继续页将上次响应 nextCursor 原样放入 filters.cursor；scope、search 和 nativeParentId 保持相同。服务端按原生 ID 的整数值升序返回，终页 nextCursor=null。每次请求都重新验证当前权限与完整来源，随机 selector 只定位本人私有分页位置，不授予访问或执行权限。

相同 cursor 重放返回相同页和下一游标。服务端绑定 tenant/member/user、完整请求 scope、规范搜索/父级、排序/页长、当前角色范围指纹、完整 source/run、授权/binding 版本及量纲证明；不能把另一用户的游标、不同筛选或新批次混入当前列表。每页 syncedAt 沿用同一持久完整批次抓取时间，未知源更新时间或金额继续明确未知，不以抓取时间或0填充。

私有链最长600秒并受有效证明期限约束；总来源最多10000行，不支持用父级筛选隐藏超界或失败来源。每身份最多32条活跃链、3200条位置记录，过期按整链有界清理。其他资源仍保持其原只读事务和游标限制。

错误边界：非法格式422；失效、不可见、过期、筛选/来源/权限指纹变化或三次序列化冲突耗尽为受控409；当前权限被撤销按既有403/能力错误拒绝；上下文容量超限429。错误不返回他人的游标、数据库异常、原始载荷或凭据。客户端应重新请求首屏，不能在失败后继续拼接新旧页。

此合同取代上一级历史初版“超过1000拒绝、无cursor”的限制。实际验收覆盖12页1101条及游标重放；10000行是本地完整源/清理用例边界，不声称实际前端消费了10000条。真实平台、生产部署、浏览器和人工验收未在本次文件消费中完成。
