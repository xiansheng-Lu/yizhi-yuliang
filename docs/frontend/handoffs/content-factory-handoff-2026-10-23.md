# 内容工厂专业工作区交付 · 2026-10-23

本次将内容工厂五个入口从步骤占位改为专业编辑工作区，并将素材资产库接入同一套本地作品和文件。页面沿用驭量的导航、授权、商品上下文和浅色视觉。

## 页面与交付能力

| 页面 | 工作区 | 已实现 |
| --- | --- | --- |
| `/app/planning` | 内容策划专员 | 创意简报、人群、渠道、目标、卖点、正文、Markdown 导出、创建关联脚本 |
| `/app/scripts` | 内容策划专员 | 口播正文、分镜增删/复制/排序、镜头时长、送去视频或图文制作 |
| `/app/graphics` | 平面设计专员 | 多画板、常用/自定义尺寸、文字与图片图层、拖动、坐标/尺寸/颜色、锁定/隐藏/排序、真实 PNG 导出与本地入库 |
| `/app/videos` | 视频制作专员 | 可拖动节点、端口连线、环路校验、参考素材、脚本上下文、画幅/时长/分辨率、已有成片绑定、进入剪辑 |
| `/app/editing` | 视频剪辑专员 | 视频/音频/字幕轨道、播放头、片段分割、素材入点/时长/位置/音量、字幕预览、画幅、工程 JSON 导出 |

所有页面支持作品列表、商品关联、本地草稿、复制为新版本和撤销。策划 → 脚本 → 视频/图文，以及视频 → 剪辑会先保存，再携带来源作品、商品、创意简报、正文或分镜进入目标页面。目标工作区仍需获得账号授权。

## 保存与文件边界

- IndexedDB：`yuliang-content-v1`，`drafts` 与 `files` 两个存储区。
- 所有本地数据按数据模式、企业、用户、店铺隔离。商品必须来自当前授权店铺；业务快照来源必须与身份模式一致。
- 文档、元数据及新文件在同一读写事务内提交；容量不足不会报告保存成功。
- 整个工作区使用递增 revision。旧页面提交时拒绝覆盖新页面保存的草稿，并提供工程/文稿备份入口。
- 未保存时拦截应用内链接与全局经营范围切换，并注册浏览器离开提示。导入中禁止编辑和重复提交。
- 工程/文稿备份不嵌入媒体；文件可在素材库单独下载。本地草稿不具备跨设备同步能力。
- 视频预览针对当前片段；字幕可叠加预览。音轨混音、整条时间线合成和最终 MP4 导出需要渲染服务。
