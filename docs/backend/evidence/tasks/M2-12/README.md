## 实现与三条DoD

1. 0031增加api_idempotency，命名空间tenant/caller/operation/key_digest唯一，绑定规范化业务载荷SHA256和服务器授权引用，不保存原始键或请求体。键不授予权限，摘要稳定不依赖可轮换审计密钥；当前只注册六种数据库命令操作，不接受任意HTTP路径/供应商写。调用方传已通过请求模型规范化的model_dump(mode=json)，canonical排序确保键序不同不误判。相同键/载荷重放首次业务结果快照；不同载荷IDEMPOTENCY_MISMATCH 409，不执行handler。首次快照仅含有界2xx/确定性4xx业务body，无Cookie/响应头/传输Envelope；将来HTTP层仍为每次请求添加当前requestId/头，不能把原业务快照当实时查询结果。
2. begin先以独立事务持久IN_FLIGHT、操作/范围/首request与审计，返回仅内存持有的高熵owner secret，数据库仅存SHA256，模型repr/序列化均不带secret或ticket。execute用受控函数NOWAIT锁原行、核对当前有效身份/owner/窗口，重做目标授权；数据库handler、副作用、首次结果和完成审计同事务。JobApplications.create增加可复用既有业务Session的unit_of_work入口，默认事务行为不变，幂等回调真实创建申请时不会偷偷开启独立提交。已知4xx用保存点回滚部分副作用后保存第一次错误；未知异常或进程退出使整个业务事务回滚，独立IN_FLIGHT仍可按原键查询。并发处理或尚未可恢复返回LOCKED/IN_FLIGHT说明，不能闷头重开。
3. recover仅对已到期、能取得PG行锁且仍IN_FLIGHT的同调用者记录换owner；活跃事务即使处理时间长也不能被并发抢走，旧owner失效。因为仅允许同PG事务操作，IN_FLIGHT且无活跃行锁意味着未提交业务与首次结果，可安全恢复；此证明不能用于任何外部IO，平台发送必须走M2-13 attempt账。COMPLETED不可再次finish或换新结果。运行身份不能UPDATE/DELETE行；键无短TTL清理，保留至业务归档策略明确后整体处理，不能按处理租约到期删键重用。

CommandAuthorization为当前六种操作显式接入：创建时读取真实内部目标和当前动作/店铺/账户权限，保存安全目标引用；后续阶段按精确job_state_context当前权限授权。begin重放、lookup、execute、recover均用原引用重核当前授权，撤权后不能借旧成功body或owner读取结果。不同租户/调用者/操作可用相同键，不能取到其他命名空间记录；没有授权实现缺省关闭。此为同事务服务原语，公开任务HTTP/F06/F11浏览器集成由后续卡装配，不能宣称未实现接口已验收。
