## 交付与DoD

1. 按账户/连接器/产品线/动作/读写/目录版本保存不可变绑定与追加证据。六阶段按前缀和核验顺序生效；前序缺失、FAIL、过期或更新后后序仍旧均降级。来源或上下文改变需新绑定，账户状态/标识变化停用旧绑定。读写证据类型不混用，多个必要绑定的动作聚合需全部通过。
2. 普通写必须完整六阶段及对应动作/对象范围。首次验证仅前五阶段有效且没有既往执行结果，另需他人批准的账户/动作/请求键/冻结载荷摘要/金额上限/时间窗许可。数据库再查当前申请人、审批人及各自范围、账户、版本、最新证据，原子消费一次。不同请求键也不能在同一绑定原结果核对前领取第二次尝试；UNKNOWN保持冻结，不自动重放。运行账号不能录入证据、自授许可或恢复已用次数。
3. 只读用READ_SCHEMA/READ_RESULT，不能借读成功放行写。六态为AUTHORIZED/UNAUTHORIZED/NOT_INTEGRATED/NOT_APPLICABLE/FORBIDDEN/ERROR。巨量、小红书及微信豆保持NOT_INTEGRATED、operations=[]，ADQ与wxpromo的账户/产品线证据互不继承。
