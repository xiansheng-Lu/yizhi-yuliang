# 内容完成后的投放账号关联

已在内容工厂工作区和素材详情增加“关联投放账号”。沿用驭量蓝白色系，交付面板使用成品预览与账号选择两栏布局，手机端改为纵向布局。

- 图片：“完成并关联”渲染当前画板为 PNG，入库后打开交付面板。
- 策划 / 脚本：文稿入库后打开交付面板。
- 视频 / 剪辑：从工作区入口选择已有成品，或在面板导入成片。剪辑工程及时间线不冒充已渲染 MP4。
- 素材库：详情显示关联账号和数量，支持管理已有记录。
- 支持平台切换、账号搜索、跨平台多选、移除关联。选择文件时显示入库时间，分别记录各个成品版本。

## 授权与存储

API 模式通过既有 `PlatformService.context(productLine)` 获取账号，校验企业、用户授权店铺、经营主体、产品线、账号授权和店铺授权关联。保存新增关联前重新读取对应产品线的授权信息；授权失效或跨店铺账号无法新增关联。接口失败时显示错误，不回退使用演示数据。

MOCK 模式仅使用当前企业 / 店铺的演示账号，并明确标识。账户关联记录保存在 `ContentAsset.accountLinks`，含平台产品线、账号 ID / 名称、平台原生 ID、经营主体、企业、店铺、模式、关联人及时间。旧草稿不含此字段时继续兼容。

成品文件与关联记录复用原 IndexedDB 原子保存、版本冲突和空间不足处理，按模式 / 企业 / 用户 / 店铺隔离；新增关联前验证实际本地文件仍可读取。移除已有关联无需原文件可用。关联按产品线 + 账号去重，不改变已归档成品；新文件需另行关联。

## 当前接入边界

现有后端契约没有内容与投放账号关联的保存接口。本次完成前端交付流程及本地关联存储，界面显示“本地关联 · 待同步”；不会发起素材上传、审核提交、广告创建或扣费。API 账号授权只用于确定可选范围，不代表该账号已经具备某类素材的上传能力。

后端接入时应保存成品与账号的关联，并返回平台素材 ID、上传 / 审核状态；平台动作仍需服务端按账号和素材类型校验权限、格式及能力。当前记录不充当任何执行凭证。

同时将内容工厂样式放到前端统一布局加载，修复页面切换时动态组件样式偶发丢失的问题。
