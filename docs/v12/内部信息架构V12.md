# 内部信息架构 V12（R1）

`/app/command` 为默认 AI驭量中枢。保留 21 个旧业务 ID，新增中枢及用户中心 `/app/account`。客户主导航固定六项；原 `workspaces` 保留为 G1 路由兼容注册表，不用于导航呈现。

| 新导航 | 路由与页面 |
| --- | --- |
| AI驭量中枢 | command：直接入口 |
| 经营概况 | overview：直接入口 |
| 直播运营 | monitor：AI直播作战室；products：商品与货盘 |
| 投放管理 | goals：经营目标；plans：投放计划；decisions：AI投手决策；budgets：跨平台预算；executions：执行记录 |
| 内容中心 | planning：内容策划（含脚本与分镜）；videos：视频创作；graphics：平面创作；editing：智能剪辑；assets：素材库 |
| 数据复盘 | analytics：经营分析；reports：完整复盘 |

内容策划统一管理原策划和脚本草稿，保留文稿 ID、版本与素材引用。原 `/app/scripts` 转入 `/app/planning`，原 `/app/experiments` 转入 `/app/assets`，保留查询参数；旧脚本授权可继续进入内容策划。

所有 ID 使用 `/app/{id}`。前两项直接进入，其余分组保持展开/折叠。侧栏底部为账号入口（登录后显示用户中心）和 APP端；不再提供管理设置、返回官网、退出演示。退出登录仅保留在用户中心。`tasks` 通过中枢与用户中心进入；后台管理页面不列入客户授权。

桌面侧栏顶部提供展开/收起按钮；收起为 72px 图标栏，保留六个业务入口、用户中心和 APP端，图标带名称提示并可直接进入对应工作区。当前分组内有活动页面时保留该页面，否则进入该分组第一个已授权页面。切换到窄屏时恢复完整抽屉导航。

API 模式使用服务端 `Identity.workspacePages` 白名单过滤导航、搜索、用户中心工作台与深链。未授权的登录目标进入用户中心；业务快照加载失败不阻止已验证用户管理个人资料。手机侧栏可用关闭按钮、遮罩或 Escape 关闭，关闭后不可聚焦。

默认登录和 `/app` 进入 `/app/command`。官网冻结文件原本使用 `next=overview` 表示默认工作台，该裸参数在登录目标解析中映射到 command，无需改变官网。显式 `/login?next=/app/overview`、旧 `#/overview` 仍访问经营总览；`campaigns → plans`、mobile 以及其他白名单深链保持兼容，非法目标只回退内部指挥台。

顶栏经营上下文复用原有 ScopeControls / Service：店铺、直播场次和平台，跨页保留，同一范围用于三项 KPI 和任务列表。账户级专业操作及平台子路由在 R3 实施；本轮未伪造账户授权或账户筛选能力。

中枢首页按对话式工作台呈现，包含运营协作、内容创作、经营分析快捷项和输入框；原右侧自主运营、待办和流程卡已移除。侧栏导航下方提供项目与最近对话，可创建项目、回看对话、按项目归类对话和已有任务。对话用 `?conversation={id}` 打开，项目用 `?project={id}`，任务记录用 `?task={jobId}` 打开；不改变既有业务路由 ID。

每次发送会保存用户消息、助手处理结果与统计范围；创建的任务通过消息 ID 关联。已有结构化任务直接出现在最近记录中；关联对话后由对话提供任务入口。项目归类不改变审批、执行或核验状态。Mock 使用按用户隔离的本地存储，API 使用独立后端；未接入真实模型时不模拟 AI 回复。当前搜索仍为工作区搜索，尚未提供全文会话搜索和重命名。
