## 三条DoD与交付

1. GET `/v1/connections` 返回`{connectors,connections}`；前者严格使用前端8个ConnectorId、五态、scopes、nullable checkedAt。范围由当前管理员会话与ALL_TENANT连接管理权限决定，UUID/账户关联不接受客户端自填。scopes取实际授权记录，checkedAt来自已记录的核验时间，未知保持null。适配器默认未装配，目录或scope存在不能开放operations。测试显式注入的合成只读适配范围也只投影六阶段有效的READ操作，本卡不开放WRITE/SUPPORTED。资源健康读取M1-16的真实本地快照，新鲜度两时间独立展示。
2. GET `/{id}/disconnect-impact` 返回账户、能力绑定、启用同步源、在跑同步、申请与在途/待回读请求ID和保留请求数。DELETE `/{id}` 接收严格`{impactDigest}`，要求会话CSRF，复核最新权限与影响面HMAC。数据库受限函数校验原会话/当前身份/租户，按账户独占锁与新平台意图共享锁串行；影响面变化返回409。成功原子撤销本地授权、递增版本、冻结相关能力/同步、登记不可改断开记录并追加审计；审计失败整笔回滚。相同摘要重放返回原影响面，不重复审计。
3. API只查白名单授权元数据，无access/refresh token或密文响应。影响面函数仅为具备完整管理范围的当前管理员返回安全ID/数量，不放开其他人的私有请求/原文RLS。保留缓存、原始请求/响应、能力证据、申请与在途核对；已提交出站意图的回执可继续落档。超过1000项明确拒绝，无静默截断。

所有路径以`/v1/connections`为前缀。POST `/{id}/refresh`校验会话/CSRF/权限后，在M1-06/07真实重授入口未装配时明确CAPABILITY_UNAVAILABLE，不伪造URL、不将旧证据复活。断开响应`providerRevocation=NOT_REQUESTED`准确表示本地停用；没有调用供应商撤权接口。重新授权应建立新的授权与对应核验，不自动启用旧绑定。
