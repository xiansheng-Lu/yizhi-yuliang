## 三条DoD

1. 0019提供sync_sources/sync_runs、分页意图、提交页与稳定字段镜像。每页必须关联M1-03b中已确认成功的只读档案；HTTP200、429、500和未发送意图不能作为确认数据。页记录、镜像upsert、计数与确认游标同一PG事务，任一步权限故障都回滚。原HTTP档案保留，不能因映射失败丢失平台观察。游标用版本化AES-GCM加密、HMAC比较，不以原文进入摘要。
2. 批次幂等键绑定上下文/查询/发起人；同批领取互斥，页按run/page幂等，改内容拒绝。每批保持一个租户、账户、绑定与查询范围，源版本和租约令牌共同拒绝旧处理者覆盖。租约到期可从最后确认页恢复，未提交页不会增加计数或标成功；新租约为安全的幂等读取创建新outboundId，原出站键不重发。非终页游标停滞/循环拒绝。itemsCount是已确认页的扫描条数，不宣称跨页去重对象总数。
3. 新分页调用必须经过prepare和dispatch_guard；guard与出站请求留档在同一事务锁住源行，校验当前启用状态、租约、实际Schema分页参数和查询摘要。暂停先取得源锁；暂停提交后不能创建新的平台请求档案/调用。在暂停前已经接受的请求允许记录事实并提交当前页，非终页变PAUSED，继续分页被拒绝。暂停/恢复须connection.manage与对象范围，并与审计同事务；普通操作员不能修改开关。服务没有跨租户批处理入口。
