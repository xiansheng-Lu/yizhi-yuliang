## 实现

`GET /v1/delivery/integrations/context?productLine=adq`复用实际Cookie/精确Origin，唯一参数只接受产品线，客户端不得覆盖租户、账户或操作状态。按当前角色及双范围读取实际主体、店铺、账户与多对多links，原生ID与内部UUID分别输出；未映射产品返回实际空集合。小店经营主体/店铺可独立存在，不为它们制造广告账户。

0043新增只由维护身份录入的资源与目录操作映射。每项操作分别检查当前目录、实际路径/方法、六阶段来源、实际授权版本/scope、当前成员及账户/店铺范围、依据有效期。前端额外的directory阶段只证明目录行存在；目录方法UNKNOWN不能直接放开操作，仍须独立绑定方法及完整六阶段依据，已知路径/方法冲突始终关闭。映射不能按URL后缀猜资源，也不能从只读声明生成可编辑字段。

原生关联增加native_id_snapshot，旧记录不自动回填为授权。实际发现入口link_authorization核对相同租户、产品线、实际有效授权和账户后登记快照；原生ID变化导致旧能力失效，旧关联保持BOUND，重新发现不复活旧能力。未变化的重复发现不伪造新核验时间。上下文期限最多60秒，并截断到实际授权及可用操作来源期限。

当前操作契约没有店铺级operation范围，故每项账户操作须在其全部可见店铺都满足相应权限；部分店铺mask不足时不借另一店铺开放。微信小店入口需后续逐请求店铺核验，当前backend阶段关闭。资源写接口归M3-11b，当前即使通用写绑定的六阶段完整，资源写backend/execution仍关闭；不把通用执行内核等同于资源命令入口。
