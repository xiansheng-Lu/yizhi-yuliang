投影器先锁当前租户水位行，在同一事务内给已提交未投影源逐一分tenant_seq、写投影、标记源、更新水位，锁保持到提交。扫描源的内部identity只用于批内公平排序，不保存作增量游标。较低identity的源晚提交后仍是待投影源，之后得到较高tenant_seq；较低tenant_seq的投影尚未提交时，后续投影器不能越过水位锁。

源去重标记在投影过期后仍保留，重跑不复活旧通知。固定七天清理只删过期前缀，同事务推进retained_from_seq；时钟改变时不删除较新的投影。分页用一次SQL的MVCC快照读取水位、保留边界与可见事件，跨租户/超前/过旧游标分别要求resync，分页不会把未返回的可见事件越过。

RLS按当前有效用户/租户/成员、动作权限和店铺/账户双范围过滤；任务和未知执行保留原申请私有性，审批事件额外允许当前具备范围的其他审核人。静态scope_key只是索引辅助，不代替当前资格查询。普通运行角色不能直接插改删事件源、投影或水位；仅可调用有界投影/清理函数，不能提供任意事件载荷或截止时间。
