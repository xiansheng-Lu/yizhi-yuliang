1. 0017保存请求意图/审计和逐次ATTEMPT/RESPONSE/ERROR，按requestId/outboundId关联目录、能力版本、账户/目标、可选执行引用与平台trace HMAC。请求先持久化，每次网络发送前再次核对范围；同键回放不再发送，变更内容拒绝。请求存档失败回滚审计且不发HTTP，响应存档失败保留已开始事实供原单核对。在途事实可在发起人撤权后落档，新请求被拒绝。
