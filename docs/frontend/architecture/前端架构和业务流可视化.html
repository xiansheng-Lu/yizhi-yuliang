一个外壳，四套工作台，一条从指令到核验的任务链

页面入口在 src/app，真正的分发在 WorkspaceEntry。前端只有三条数据出口：Mock 适配器、ApiClient、IndexedDB。真实平台闭环仍由独立后端承接。

Next.js 16.2.6 · React 19.2.6 · Node 24.19.0 · 23 个白名单 pageId · 14 个主导航入口

01 / 分层

页面在 App Router，业务在 WorkspaceEntry 之后分叉

所有请求先穿过同一个外壳：身份、授权、快照、导航。工作台只负责本域界面，数据读写一律落到 lib 与 services。

mode: "mock" 时 WorkspaceProvider 注入固定服务和全量页面白名单；mode: "api" 时必须由后端下发可用页面，否则一律不渲染工作台。这条规则避免了“前端偷偷放行”的权限漏洞。

03 / 状态与落盘

状态分五层，只有内容和复盘缓冲真正落盘

身份、服务、快照放在全局；项目与对话放在中间层；投放草稿只活在当前会话。刷新就消失，是刻意的边界。

一致性快照读取器按 owner key 与最小间隔去重。并发请求合并成一次；失败按指数退避；旧结果只在监控页保留，并明确标注“并非最新”。

04 / 业务流

六条主链路，都从“当前范围”出发

范围决定一切：平台、店铺、账户、日期。任何一条链路在范围变化后都会重新读取，而不是沿用上一次的结果。

4.1 进入：先确认身份，再确认授权

会话失效时 ApiClient 收到 401，身份状态被清空；深链的 next 只在同一站内且通过白名单才保留，否则回到 /app/command。

4.2 AI 中枢：先解析，再生成带幂等键的任务

  • 7 类广告动作：调整预算、出价、状态、定向、时段、商品与创意。每类都落到固定的值类型与执行记录。
  • 幂等：创建任务、发送消息、确认、取消各用一枚键；结果未知时保留原键等待查询，绝不盲目重放。
  • 时效：草稿类任务 15 分钟后过期；同一对象 5 分钟内不重复生成。

4.3 投放：配置、预检、审批、回读，缺一不可

配置由产品目录生成，而不是前端写死字段。ADQ 与微信豆复用投放模型，千川、巨量、DOU+、本地推、聚光、小店版各自拥有独立的资源选择器与字段约束。结果未知时保留幂等键，查询原任务，不重放写入。

4.4 内容工厂：能产出 PNG 与工程，上传仍等后端

剪辑工程保存轨道、片段与字幕，不导出整段视频。整条时间线混音与 MP4 渲染被明确标为依赖能力，界面上不提供假按钮。

4.5 直播与货盘：四个模块共享一次快照

货盘的上下架与排序先写本地草稿，再按能力决定能否提交平台。库存、价格、链接的差异在提交前逐项列出，避免把整盘商品一次性推给平台。

4.6 数据复盘：分析、草稿、发布是三段不可变流程

维度可选店铺、直播、投流、短视频，一次 1 至 4 项。日报必须 1 天、周报必须连续 7 天、月报必须完整自然月；周期不匹配时直接拦截，不生成半成品报告。

05 / 任务状态机

十二个状态，成功只认回读匹配

任务不是“提交成功即成功”。执行器返回受理后还要回读核验；核验不一致就进入失败，而不是标记完成。

06 / 服务与接口

七组服务对应各自的接口命名空间

页面只依赖服务接口，不依赖具体后端路径。Mock 与 API 两套适配器实现同一组方法签名，切换数据模式不改页面代码。

快照读取Workspace snapshot概况、直播、任务、计划、货盘

传输约定Cookie 会话 + cache: no-store + 15 秒超时 + X-Yuliang-Client: web。遇到 401 清身份，409 拉最新版本，429 按 Retry-After 退避。

接口业务失败返回 202 加业务码，不走 4xx；移动端与电脑端共用一个客户端标识，后端据此区分渠道策略。

07 / 实现边界

哪些闭环在前端完成，哪些仍等后端

判断标准很简单：是否需要真实平台写入或真实模型产物。不需要的，前端已闭环；需要的，只展示状态，不伪造结果。

业务域前端已实现依赖后端 / 平台状态
登录与身份密码、邮箱验证码、Mock 身份、会话失效处理真实账号体系与权限下发契约完整
工作区与授权页面 / 动作 / 账户 / 能力四层判断后端返回可用页面与授权账户契约完整
投放配置产品目录、草稿、完整校验、预检交互预检签名、平台真实校验待联调
投放执行任务确认、审批流、执行记录、回读展示执行器、风控、平台写接口待联调
内容创作策划、画布、剪辑工程、PNG、素材库平台上传、审核、素材 ID本地闭环
视频渲染轨道编辑、工程 JSON、预览占位整条时间线混音、MP4 渲染未接入
数据复盘条件、任务、结果、草稿、预览、HTML 导出真实指标计算与发布链接Mock 可跑

红线前端不伪造平台成功。没有回读匹配，就不展示“已生效”；没有真实模型产物，就不提供“已生成视频”。
